# Просёлок

Мобильный трёхмерный симулятор вождения по российской деревне. Игра использует собственный компактный WebGL-рендерер и не загружает внешние библиотеки или ресурсы.

## Первая версия

- цельная низкополигональная 3D-деревня с домами, лесом, рекой, мостом, фермой, станцией и пилорамой;
- оригинальный четырёхдверный седан с салонной, внешней и верхней камерами;
- фиксированный шаг физики, автоматическая передача и задний ход;
- асфальт, мокрый асфальт, грунт, гравий, трава, песок, грязь и мелкая вода;
- сенсорный руль, альтернативные кнопки, газ, тормоз и ручник;
- топливо, повреждения, ремонт, заправка и улучшения;
- пять последовательных заданий;
- день, ночь и дождь;
- синтезированный звук двигателя и тактильная отдача;
- сохранение в IndexedDB и автономный PWA-режим;
- клавиатурное управление на компьютере.

## Управление

На телефоне используйте виртуальный руль слева и педали справа. Кнопка `D/R` меняет направление после остановки. На компьютере работают WASD или стрелки, пробел, E и F.

## Проверка

```bash
npm ci
npm run check
npm test
npm run build
```

Production-сборка создаётся в `dist` и публикуется через GitHub Pages.

## Ограничения

Первая версия использует стилизованную физическую модель без деформации кузова, сложной трансмиссии и сетевой игры. Трафик, жители, ручная коробка, отражения в зеркалах и управление наклоном телефона запланированы для следующих выпусков.
