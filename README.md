# Банановые коты: Мышиный переполох

Оригинальный мобильный 2D-платформер для вертикального экрана. Два котика с портретами героев преследуют мышей, используют банан-бумеранг и возвращают Золотой банан.

## Что есть в игре

- четыре законченных уровня: кухня, кладовая, крыши и сырная крепость;
- два героя с разными характеристиками и мгновенным переключением;
- напарник, который следует за игроком и помогает в ближнем бою;
- четыре вида мышей и финальный босс Барон Мышильдо;
- банан-бумеранг, прыжок сверху, контрольные точки, очки и бонусы;
- сенсорное управление, адаптированное под портретный экран 9:16;
- управление с клавиатуры для разработки и проверки;
- синтезированные звуки без внешних аудиофайлов;
- локальное сохранение рекорда и разблокированного прогресса;
- PWA-режим и офлайн-кэш после первого запуска.

## Управление

На телефоне используются экранные кнопки. На клавиатуре:

- `A` / `D` или стрелки — движение;
- `Space` / `W` / стрелка вверх — прыжок;
- `X` / `K` — бросить банан;
- `Q` / `E` — сменить ведущего котика;
- `P` / `Esc` — пауза.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Открыть `http://localhost:8080`. Модульный JavaScript и service worker требуют HTTP-сервер; открытие `index.html` напрямую через `file://` не поддерживается.

## Проверки

```bash
npm test
npm run check
```

Проект не использует сторонние JavaScript-зависимости. Публикация выполняется через GitHub Pages после успешных проверок.

## Авторские материалы

Игровая механика относится к жанру классических платформеров, но графика, персонажи, уровни, интерфейс, звуки и код созданы специально для этого проекта. Ассеты Nintendo не используются.
