# Рязанский проспект: Последний рейд

Самостоятельная мобильная 2D-игра на TypeScript, Vite и Phaser 3. Изолированный проект в `last-raid/`; остальные приложения репозитория не заменены.

## Запуск

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

Production находится в `dist/`. Статический хостинг без серверной части. Путь Vite относительный, игру можно публиковать в подпапке. Для QA-сборки: `RAID_QA=1 npm run build`; она дополнительно создаёт `qa.html` и изолированный тестовый вход `qa-game.html`. Обычная сборка их не включает.

## Управление

- Телефон: аналоговый джойстик слева; ✦ усиленный удар; ➤ рывок; ⇄ смена героя; ✹ граната после открытия.
- ПК: WASD / стрелки; Space удар; Shift рывок; Q / Tab смена героя; G граната; Escape пауза.
- Обычный бой автоматический. Второй герой следует по сетке обхода препятствий и атакует самостоятельно.
- Коля быстрее и чаще бьёт; Валера имеет больше здоровья и сильнее отбрасывает врагов. Здоровье отдельное. После гибели активного управление переходит к живому герою.
- Уровень отряда повышается строго каждые 10 убийств. Новое оружие всегда доступно среди трёх вариантов, пока арсенал не заполнен. Можно выбрать характеристику и отложить оружие.
- Опыт начисляется за убийства сразу. Подбор оставшихся зелёных осколков немного ускоряет готовность усиленного удара. Аптечки лечат, припасы пополняют гранаты, янтарное усиление временно повышает урон.
- Боссы назначаются каждые 50 убийств и выходят по очереди, если предыдущий ещё жив: Баранов, Замараева, Курилюк, Тётя Гри. Следующий цикл сильнее. Все боссы вымышлены.

## Архитектура

- `src/main.ts`, `src/style.css`: интерфейс, экраны, настройки, HUD, локальные рекорды.
- `src/scene.ts`: игровой цикл, герои, оружие, враги, боссы, предметы и эффекты.
- `src/world.ts`: отрисовка видимых секторов 512×512, препятствия и BFS-поле навигации на сетке 32 единицы.
- `src/rules.ts`: чистая логика прогрессии, очереди боссов, гранат, сохранений, пространственных корзин и пулов.
- `src/input.ts`: независимые Pointer Events, захват джойстика, обработка отмены, клавиатура.
- `src/art.ts`: атлас оригинальных рисованных врагов и игровые текстуры.
- `src/audio.ts`: оригинальные синтезированные звуки через Web Audio после действия пользователя.
- `tests/rules.test.ts`: тесты правил. `src/qa*.ts`, `qa*.html`: отдельный браузерный стенд с размерами 390×844, 430×932, 320×740, 844×390, синтетическими одновременными Pointer Events и 180-секундной нагрузкой.

180 слотов врагов, 200 снарядов, 180 эффектов, 50 опасных зон, 100 предметов, 24 броска. Повторное использование слотов. Числа урона ограничены 30 объектами. Враги появляются вне камеры. Сектора удаляются вместе с текстурами после ухода камеры. DPR игрового холста 1: это осознанное ограничение нагрузки на мобильный GPU. Частота и качество фоновых эффектов адаптируются без изменения правил боя.

## Карта, источники и лицензии

**Спутниковая подложка не используется.** Карта построена по реальной геометрии OpenStreetMap, загруженной 14 сентября 2026 года из официального API:

https://www.openstreetmap.org/api/0.6/map?bbox=37.779,55.710,37.807,55.727

Область: 37.779–37.807° E, 55.710–55.727° N. Масштаб 3 игровых единицы на метр; поле 5267×5677. Сохранены 1959 объектов дорог, зданий и входов метро. Геометрия компактно сохранена в `public/map.json`, без пользователей OSM и истории правок. Конвертер `scripts/import-osm.py` воспроизводит преобразование исходного XML.

© OpenStreetMap contributors. Данные и производная база `public/map.json` предоставляются по ODbL 1.0: https://www.openstreetmap.org/copyright и https://opendatacommons.org/licenses/odbl/1-0/. Атрибуция размещена на стартовом экране; файл геоданных открыт в репозитории. Автомобили, деревья, мусорные контейнеры, заборы и прочий декор являются игровыми, их фактическое размещение не утверждается. Столкновения используют дискретную сетку, поэтому очертания препятствий могут отличаться от геометрии на долю клетки.

Ориентиры проверены по OSM и открытым сведениям:
- Метро «Рязанский проспект»: https://mapy.com/en/?id=11645372&source=osm и https://2gis.ru/moscow/directions/points/%7C37.794463%2C55.71705%3B4504385606387245
- Финансовый университет, 4-й Вешняковский проезд, 4 к1: https://www.fa.ru/university/structure/scientific-educational-departments/itabd/ ; здание OSM https://www.openstreetmap.org/way/129710008 (подпись в игре вычисляется по координатам здания).
- Улица Паперника и Рязанский проспект: координаты узлов соответствующих именованных дорог в `public/map.json`.

Изображения героев созданы специально для проекта по предоставленным фотографиям. Исходные фотографии не входят в репозиторий или сборку. Использован встроенный imagegen, затем техническое удаление одноцветной хромакей-подложки, уменьшение и упаковка WebP без EXIF. Персонажи, одежда и портреты оригинальные; приложенный игровой скриншот использован только как стилистическое направление. Звуки генерируются программно, чужой музыки нет. Phaser 3: MIT, https://github.com/phaserjs/phaser/blob/v3.90.0/license.txt. Лицензии инструментов находятся в установленных пакетах.

## Ограничения

Проект не воспроизводит фотографический спутниковый вид. Герои анимируются сменой ракурса, покачиванием и эффектами атак, без полной покадровой анимации скелета. Локальные результаты относятся только к этому браузеру и устройству. После ухода приложения в фон включается пауза. Поддержка вибрации зависит от браузера; iOS может не поддерживать `navigator.vibrate`. Нет регистрации, облачных сохранений или сетевой игры.

Цель 60 FPS не является обещанием частоты кадров на конкретном телефоне. Проверки в облачном Chrome не заменяют тестирование на настоящем iPhone. Результаты выполненных проверок описаны в `QA.md`.
