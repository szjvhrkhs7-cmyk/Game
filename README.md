# Crown & Conquest: Европа 1095

Оригинальная браузерная пошаговая стратегия о средневековой Европе. Игра запускается без сервера и внешних зависимостей, работает на компьютере и мобильных устройствах и сохраняет кампанию локально.

## Что реализовано

- цельная пергаментная карта Европы, Северной Африки и Ближнего Востока из 229 регионов;
- географические береговые линии, острова, моря и плотная внутренняя сетка владений;
- восемь игровых держав с разными бонусами и стартовыми условиями;
- экономика, продовольствие, авторитет и общественный порядок;
- 13 типов построек, ограниченные ячейки и очереди строительства;
- восемь классов войск, требования, срок найма и содержание;
- самостоятельные полевые армии, гарнизоны, снабжение, дух и опыт;
- поиск маршрута, стоимость местности, объединение армий и передача отрядов;
- осады, истощение гарнизона, штурм и снятие осады;
- быстрый расчёт и упрощённое тактическое сражение с построением и пятью приказами;
- дипломатия, торговля, мир, союзы, вассалитет, дары и объявления войны;
- ходы компьютерных держав и события кампании;
- условия победы и поражения;
- версионированное локальное сохранение, безопасное восстановление и PWA;
- масштабирование колесом и жестом, перетаскивание с инерцией и адаптивная детализация;
- адаптивный интерфейс с клавиатурным управлением и поддержкой reduced motion.

Границы регионов построены на основе общедоступных геоданных Natural Earth и художественно адаптированы под средневековую кампанию 1095 года. Это игровая карта, а не точный исторический атлас.

## Игровой цикл

Выберите одну из восьми держав, развивайте поселения, планируйте производство, собирайте полевые армии, заключайте договоры и ведите войны. Армии прокладывают маршрут по соседним регионам, расходуют очки движения с учётом местности и не могут мгновенно захватить укреплённое поселение. Перед сражением можно выбрать построение и боевой приказ. Кампания завершается после захвата 55 регионов либо шести столиц.

## Запуск

Откройте `index.html` в браузере либо запустите любой статический сервер:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Проверка

Требуется Node.js 20 или новее.

```bash
npm test
npm run check
npm run build
```

Проект автоматически публикуется через GitHub Pages после успешного прохождения проверок.

## Границы текущего выпуска

Тактическое сражение намеренно выполнено как быстрая двухмерная командная модель, без управления сотнями отдельных бойцов в реальном времени. Морские перевозки, династические браки, полноценный туман войны и синхронизация сохранений между устройствами запланированы для следующих выпусков.
